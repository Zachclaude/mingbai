# 明白 · 办事助手

Live demo: https://zachclaude.github.io/mingbai/

把办事通知整理成一张能带走、能核对、照着做的清单。离线优先，单文件，无后端。

v4 起：把通知原文粘进来，本机规则自动挑出日期、时间、地点、电话和要带的材料，核对后生成清单。

- 直接打开 index.html 即可使用，也可以放到任意静态托管
- 支持粘贴识别（纯前端规则，字面匹配，不联网、不调用 AI 接口）
- 十类常见通知：照护评估、养老金、医保报销、用药调整、出院、社区照护转介、低保/困难救助、残疾证、社保卡、助餐助浴与适老化改造
- 打印：页面内「打印，带去窗口」，A4 一页（页眉、日期、复选框、要带物品）
- 清单页：材料勾选与缺口、截止日倒计时、一键打电话稿、复制给家人、ICS 日历、朗读
- 家属接力：需要网页已上线，复制「复制给家人的链接」发给家人
- 不联网、不收集数据；通知原文与填写内容只存在本机浏览器
- 识别结果是提示，不是政策依据；具体要求以通知原文和经办机构确认为准
