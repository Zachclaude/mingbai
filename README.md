# 明白 · 办事助手

Live demo: https://zachclaude.github.io/mingbai/

把办事通知整理成一张能带走、能核对、照着做的清单。离线优先，单文件，无后端。

- 直接打开 index.html 即可使用，也可以放到任意静态托管
- 打印：页面内「打印，带去窗口」，A4 一页
- 家属接力：需要网页已上线，复制「复制给家人的链接」发给家人
- 不联网、不收集数据；填写内容只存在本机浏览器

## 目录

- index.html   全部页面（单文件）
- brand/       字标与图标
- .nojekyll    让 GitHub Pages 原样发布
